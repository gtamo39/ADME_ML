▶ MPO score — weighted formula
logd = raw predicted value · c('logd') = confidence · sigmoid('logd', 3) = desirability 0–1, center = cutoff (defaults to the config cutoff if omitted; optional slope sigmoid('logd', 3, 2)) — the favorable inequality (e.g. mdck ≥ 10, hlm < 12) sets the direction, so every term is 1 = good, 0 = bad · d(…) is the same as sigmoid(…) · sigmoid(x, center, slope) = manual numeric form. Helpers mean(…) min max clamp exp log abs pow. Example: 0.4*sigmoid('logd',3) + 0.3*sigmoid('solubility',10) + 0.3*sigmoid('hlm',12)
▶ Filters
show a compound when it passes
A term reads property operator value — e.g. mdck > 1, solubility > 10, solubility_conf > 0.5. The grid updates on every keystroke. Properties: each endpoint (raw predicted value), each <endpoint>_conf (RF confidence 0–1), plus MPO and the manual Score column. An incomplete term is ignored. A compound with no value for the property fails the term. Filtering only HIDES rows — it never re-scores them, and the CSV download takes the visible selected rows.
▶ Columns
Unticking a column only hides it in the grid. Hidden columns are still scored, still filterable, and still written to the downloaded CSV.

Defaults are the SERAC palette from config.yaml: olive #74B24A (favorable), azure #0EA5CE (confidence above the split) and ember #E65D32 (confidence below it). The MPO column follows the favorable color. A color choice lasts for this page load only.
The value triangle fades instead of switching: it is pale at the triage cutoff and saturates as the prediction moves away from it, in the endpoint's modelling space (per log unit for a log endpoint). value fade scales that steepness — left is a smoother ramp, right is closer to a hard cutoff. The per-column default comes from webapp.color_slope in the config.
cell split chooses the shape of the boundary between the value and the confidence: curved is an arc through the cell, straight diagonal is the classic corner-to-corner split. Both keep about half the cell for each reading. blend sets how wide the two colors mix across that boundary: hard (0%) gives a crisp edge, soft spreads it into a wide gradient. The straight split also draws a hairline, which fades out as the band widens.
